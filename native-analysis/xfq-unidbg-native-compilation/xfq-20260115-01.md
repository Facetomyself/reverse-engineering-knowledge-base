unidbg 更稳定的打调用栈
原版unidbg提供一个api： unwind 获取调用栈，但存在一个问题，总是崩溃； 所以我是用下面这个获取的，可能效果不太好，后续有空改unidbg源码修复一下前面的问题
使用：
emulator.attach().addBreakPoint(module.base + 0x27130, new BreakPointCallback() {
    @Override
    public boolean onHit(Emulator emulator, long address) {
        System.out.println("\n[RANDOM_DEVICE] Entry - std::random_device::operator()");
        printCallStack(emulator);
        return true;
    }
});
工具函数如下：

    long fp = backend.reg_read(Arm64Const.UC_ARM64_REG_FP).longValue();

    Module m = emulator.getMemory().findModuleByAddress(addr);
    if (m != null) {
        System.out.printf("  %-3s %s+0x%x\n", tag, m.name, addr - m.base);
    } else {
        System.out.printf("  %-3s 0x%x\n", tag, addr);
    }
}
