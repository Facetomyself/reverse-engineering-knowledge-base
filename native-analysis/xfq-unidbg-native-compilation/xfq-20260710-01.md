## 正文

gadget注入xfqtrace实现trace 步骤
其实我是推荐xfinject注入的，主要是压根没有必要用gadget;  
但是有的朋友问了，所以就还是讲一下;  实际操作下来都是一样的，跟server没啥区别
下面以两个gadget举例子，一个是开源免费的魔改server/gadget：rusda，一个是我付费588购入的小佳知识星球的gadget
一、rusda-gadget-16.2.1
去github下载16.2.1的gadget.so： [GitHub - taisuii/rusda: 对frida 的patch，产物可直接下载Relea...](https://github.com/taisuii/rusda)
然后用我的辅助脚本 inject_rusda_gadget.py 这个主要是把xfqtrace还有rusda-gadget的so都推过去，然后放到合适位置，然后用xfinject注入gadget到app中，然后卡住等待我们frida-cli 连接
然后frida-cli执行命令就行：frida -H 127.0.0.1:14725 -n Gadget -l examples/com.xiaofeng.qbdi/gadget_trace.js 
具体看图把; 
二、小佳的gadget-16.5.7
1. 安装对应的zygisk模块，然后去小工具app中启用要被注入gadget的app, 配置 对应app的config就行，然后手动打开app确认卡在开屏 代表zygisk模块生效
2. 然后把xfqtrace的so推到files目录下
后面就跟server差不多了的; 
adb -s 13081FDD4002VL push bin/libxfqtrace.so /data/local/tmp/libxfqtrace.so
adb -s 13081FDD4002VL shell "su -c 'cp /data/local/tmp/libxfqtrace.so /data/data/com.xiaofeng.qbdi/libxfqtrace.so && chmod 755 /data/data/com.xiaofeng.qbdi/libxfqtrace.so &&
  restorecon /data/data/com.xiaofeng.qbdi/libxfqtrace.so 2>/dev/null || true && ls -l /data/data/com.xiaofeng.qbdi/libxfqtrace.so'"
3. 做一下端口转发 
adb -s 13081FDD4002VL forward tcp:14725 tcp:14725
4. 注入js脚本
frida -H 127.0.0.1:14725 -n Gadget -l examples/com.xiaofeng.qbdi/gadget_trace.js
然后就正常触发trace即可
