总结常见 证书安装 方案 与 对应常见问题
方案一：用户证书利用面具模块移动（兼容性好，**覆盖场景广，群控安装也方便**）
	1. 导出电脑抓包工具的证书(一般是crt格式)
	2. 上传到手机
	3. 利用的证书安装程序：settings -> User credentials -> Install a certificate  -> CA certificate -> 去找推送的证书
	4. 利用面具模块进行移动 （这里的模块很多都有问题，本人仅推荐 [https://github.com/ys1231/MoveCertificate](https://github.com/ys1231/MoveCertificate)）
**证书安装程序崩溃或者安装之后用户证书不起效果？** 试试手动计算证书hash 制作最终版证书 .0 文件，参考上面的github
	一定要注意了，我们的目标是 拿到.0后缀的证书： 1）抓包工具自己就能导出2）可以手动转换，下面演示
	1. 找到pem证书（一般导出选项有很多，没有的话就找转换工具）
	2. 计算hash：openssl x509 -inform PEM -subject_hash_old -in  ；会出现一串短hash，和证书b64内容
	3. 拿到der证书，根据前面的hash改名为  
	4. 推送到模块提供的目录，然后重启即可：我这里是adb -d push  /data/local/tmp/cert/
方案二：利用抓包工具写好的面具模块（兼容性一般，体现在**很多手机装了没效果**）
方案三：利用抓包工具的一键安装，这个是类似 虚拟文件系统 来做的，**重启手机就没了**，适合简单测试； **这种很容易出现解密失败的问题

网上让你手动移动到系统证书模块的方案也有，但是成功率相对很低，可能你搞几小时都搞不成功，原因较为复杂**
