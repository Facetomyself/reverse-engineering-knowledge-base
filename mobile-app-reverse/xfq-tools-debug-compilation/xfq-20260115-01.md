## 正文

安卓9之后默认禁止http明文流量 ， 一个正向开发热知识，但是逆向冷知识(可能?)
缘由：在公司写lsp插件，然后往我们服务后后端传个数据，调用的api是http://ip:port/形式，死活通过不了，结果同事告诉我安卓9之后不让这么传了；
一般来说正向开发测试的时候有办法配置支持http，但是逆向就不行了；
解决方案：使用外部进程代理请求，如lsp插件发广播携带js脚本代码给到autojs框架，然后autojs执行脚本 来进行通信； 
思考：还有其他方案，比如通过hook反射临时修改某些配置从而绕过，这个我没试成功过，有尝试过的朋友可以分享一下； 还有就是直接调用curl来发，代码如下

                Process process = Runtime.getRuntime().exec(new String[]{
                    "curl",
                    "-s",  // 静默模式
                    "-m", "5",  // 超时 5 秒
                    url
                });

下面是google的android对于http/https的逐步收紧策略，可以简单参考一下；
1. 安卓6
  - 引入 usesCleartextTraffic 属性
  - 默认允许 HTTP，但开发者可以禁用
2. Android 7
  - 引入 Network Security Configuration
  - 允许细粒度控制哪些域名可以用 HTTP
3. Android 9
  - 默认禁止明文流量
  - usesCleartextTraffic 默认值改为 false
  - 强制开发者显式声明才能用 HTTP
4. Android 10+ 
  - 进一步收紧，某些系统 API 完全拒绝 HTTP
  - Google Play 要求所有网络通信必须 HTTPS
