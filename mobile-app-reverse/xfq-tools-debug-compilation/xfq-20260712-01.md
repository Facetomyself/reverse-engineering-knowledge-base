Reqable MCP 配置
  1. Reqable 自带 MCP Server：/usr/share/reqable/mcp-server

  2. Codex 直接注册：
  codex mcp add reqable -- "/usr/share/reqable/mcp-server" （你的路径和我的不一样哦）
reqable也支持各种ai相关的工具一键配置，tools->Mcp->setup mcp server 然后选你用的; 也会有提示命令，没有的话按照我下面的配也行，反正本质都一样

  3. 如果使用了我的GateWay-Mcp ：[GitHub - LunFengChen/Gateway-Mcp: 整理逆向常用mcp，做二级路由策...](https://github.com/LunFengChen/Gateway-Mcp)，把下面的配置加入 Gateway 的 mcps_config.json：
  "reqable": {
    "command": "/usr/share/reqable/mcp-server",
    "args": [],
    "profiles": ["reverse", "traffic", "reqable", "capture"], 
    "disabled": false
  }

  4. 修改配置后重新连接 Codex，然后验证：
  gateway_status(server="reqable", verbose=true)
  search_gateway_tools(query="live capture filter record", server="reqable")
  call_gateway_tool(name="reqable_capture_live_status", arguments={})
  call_gateway_tool(name="reqable_capture_live_filter", arguments={"filters":[]})

  5. Reqable 当前提供约 143 个工具，包括实时流量、断点、重写、Python 脚本、SSL 代理、限速、反向代理、集合和 HTTP/WebSocket 调试。

  6. Gateway 必须透传 MCP structuredContent，否则只能看到“调用成功”而看不到请求详情。我github新的Gateway-Mcp 已修复。
