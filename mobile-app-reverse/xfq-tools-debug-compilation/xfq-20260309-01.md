bug：某些手机在特定fridaserver运行的时候会出现下列报错
Unexpectedly timed out while waiting for syscall on android.anim thread; please file a bug!
Unexpectedly timed out while waiting for syscall on ActivityManager thread; please file a bug!
Unexpectedly timed out while waiting for syscall on NetworkPolicy thread; please file a bug!
解决方案：
1）卸载art(pm uninstall com.google.android.art)然后重启手机 
2）或者更换server版本（如16.2.1->16.1.11)
