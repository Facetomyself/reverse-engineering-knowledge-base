xfqtrace 2.1 修一些稳定性bug
具体怎么用你可以选择看docs/usage.md，只要你看得下去） 我的建议是安装好skills直接丢给ai然后给一下关键信息他自己就会开始trace了; 我用的设备是android13 pixel5(tq3a.230901.001.c2) linux内核4.19 apatch(11182) kernelpatch 0.12.7 
一、使用方案：
(1) 安装skills v0.1.6对应的pip包： pip install xfqtrace-skills 
xfq skill install --target both --force # 安装skills到codex/claude目录
xfq init ./xfqtrace-kit-2.1.zip -p  # 安装核心包，需要压缩包密码微信私我
xfq doctor # 检查包的版本、缺失等等
如果是更新skills请用：xfq update -y; skills代码纯ai写的有问题的话可以给我说我去鞭策它
(2) 准备trace
写recipe.json主要是配置你要怎么trace，一些必备参数，以及一些高级参数等等
然后 在kit根目录如：~/Desktop/projects/xf-trace/xfqtrace-kit 执行如下命令即可
python ./全自动化trace.py   --serial 13081FDD4002VL --inject-backend xfinject --clear-app-data -p ru.moneyman
其中主要是用xfinject注入核心trace的so来进行trace, 然后很多场景默认都是spawn,这里就统一这样了，-p 后跟包名
二、后面2.2更新什么：（这个版本估计更新的很慢了， 如果有一些trace出问题的样本建议直接发我）
1. 做几个指纹案例发星球，然后自己做过才知道怎么对trace工具优化（目前算法相关的问题不大）
2. 优化点如 对一些指纹参数在调用jni的时候更深的一些解析，现在2.1及之前的都停留在函数的出入口而已;  后续在某些关键jni函数的调用 直接识别jobject出为jarr的时候就直接展开，识别到常用的数据类型就正常展示
3. 准备找几个案例适配一下gadget; 还有xfinject对于 attach的方案，这样可以配合frida更方便的用
4. 无痕hook然后配合xfvmahide做一些深层注入痕迹隐藏

另外值得说的是，如果这个工具我长时间不维护了（如半年以上）会把源码发出来的;
