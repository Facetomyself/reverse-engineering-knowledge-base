WORD到底几个字节？为啥IDA是2字节，别的是4字节？
IDA 的数据类型命名习惯主要沿用了 **Intel x86 汇编语法**和 **Windows API 的历史标准**。
在早期的 16 位 CPU（比如经典的 Intel 8086）时代，CPU 的自然数据宽度（也就是一个“字”）是 16 位。为了保持向后兼容，无论是微软的 Windows API 还是 Intel 的汇编标准，都把 WORD 这个名词“锁死”在了 2 字节。

当其他文章提到 WORD 是 4 字节时，它们通常指的是以下两种情况之一：
**ARM 或其他 RISC 架构体系：** 在 ARM 架构的官方手册中，由于它原生是 32 位的体系结构，所以官方把一个 Word 定义为 **4 字节**（32 位）。而在 ARM 中，2 字节被称为 Half-Word（半字）。如果你看的文章是关于 Android 逆向或 ARM 汇编的，它们就会说 WORD 是 4 字节。
**计算机组成的广义概念（机器字长）：** 在广义的计算机科学中，“机器字（Machine Word）”指的是 CPU 一次能处理的数据宽度。对于 32 位操作系统/CPU，机器字长就是 4 字节；对于 64 位系统，机器字长就是 8 字节。
