这个玩意...

ccswitch使用
这个玩意儿主要是用一个固定不变的配置文件接管claudecode，codex。相当于一个中间人代理
好处就是你可以在软件里随时切换各种中转站，比如别人突然给你一个baseurl还有sdkey你直接快速在这里面配置就能用了。
还能管理mcp skills各种东西
坑：新版release默认不会打开本地代理，这是阉割版的，需要去配置文件打开本地代理才能体验很好，否则你就别下载使用了哈哈哈哈

下面是我使用后的claude配置文件 settings.json内容。主要是env那里
{
  "autoUpdatesChannel": "latest",
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "PROXY_MANAGED",
    "ANTHROPIC_BASE_URL": "[http://127.0.0.1:15721](http://127.0.0.1:15721)",
    "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC": "1"
  },
  "hooks": {
    "PreToolUse": [
      {
        "hooks": [
          {
            "command": "rtk hook claude",
            "type": "command"
          }
        ],
        "matcher": "Bash"
      }
    ]
  },
  "model": "sonnet[1m]",
  "permissions": {
    "allow": [],
    "deny": []
  },
  "skipDangerousModePermissionPrompt": true
}
