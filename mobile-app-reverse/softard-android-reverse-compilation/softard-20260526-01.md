## 正文

上一篇讲了怎么读汇编，正常函数的控制流图（CFG）结构清晰。但有一类 SO，IDA 打开之后 CFG 是这样的：

密密麻麻几十个块，箭头乱成一团，代码量明明不多，结构却复杂到无从下手。

这不是你的问题，是这个 SO 被  ** 混淆  ** 过了。这篇把常见的混淆手段逐一拆开讲。


##  一、基础概念：什么是基本块

在讲混淆之前，先搞清楚 CFG 里那一个个方块是什么。

** 基本块（Basic Block）  ** 是一段顺序执行、没有分支的指令序列：从第一条指令进入，从最后一条指令（通常是跳转）离开，中间不会被打断。

举个例子，这段 C 代码：


    if (x > 0) {    do_a();} else {    do_b();}do_c();

编译后会被切成四个基本块：


IDA 的图形视图（按空格键切换）里，每个方块就是一个基本块，箭头是跳转关系。正常函数的 CFG 和原始代码结构基本对应，一眼能看出逻辑。

混淆的目标就是  ** 破坏这个对应关系  ** ，让 CFG 和原始逻辑完全脱节。


##  二、控制流平坦化（CFF）

OLLVM 最核心的技术。原理是把所有基本块的跳转关系拆掉，统一接入一个中央  ** 调度器  ** ，由一个 state 变量决定下一步去哪个块：


    // 原始if (x > 0) { do_a(); } else { do_b(); }do_c();
    // CFF 处理后int state = 0x1234;while (true) {    switch (state) {        case 0x1234: state = (x > 0) ? 0xABCD : 0x5678; break;        case 0xABCD: do_a(); state = 0x9999; break;        case 0x5678: do_b(); state = 0x9999; break;        case 0x9999: do_c(); return;    }}

识别特征：CFG 里有一个被所有块反复指向的枢纽块，就是调度器。由于所有真实逻辑块都要经过它，所以真实块和垃圾块混在一起，人眼很难快速区分哪个 case
是真实逻辑。

对抗原理：state 的每次赋值都是  ** 编译期常量  ** ，跳转目标也因此固定下来。利用常量传播静态算出每条路径的真实走向，就能把 switch
还原成原始的 if-else。


##  三、虚假控制流（BCF）

在真实代码块前插入一个永远不会执行的假分支：


    // 原始do_a();
    // BCF 处理后if ((x * (x + 1)) % 2 == 0)  // 恒为真：连续两整数之积必为偶数    do_a();                    // 真实路径else    do_fake();                 // 永远不执行

这个永远成立的条件叫  ** 不透明谓词（Opaque Predicate）  ** 。IDA
静态分析时并看不出它恒为真，所以会把它当成普通条件处理，最终导致 CFG 里多出大量假分叉。

BCF 和 CFF 可以叠加——调度器里的每个 case 再套一层 BCF，复杂度因此成倍上升。

对抗原理：用  ** 符号执行 + 约束求解  ** ，让工具自动判断条件是否恒真/恒假，从而把假分支删掉。


##  四、字符串加密

前面分析 L2 的时候，  ` "Thanks for all the fish"  ` 在 Strings
窗口搜不到——那是编译器优化的副作用，不是故意的。真正的字符串加密是主动对抗逆向的手段。

做法是在编译时把所有明文字符串替换成密文，运行时调用解密函数还原：


    // 原始代码const char *key = "my_secret_key";
    // 字符串加密后const char *key = decrypt(encoded_bytes);  // 运行时才还原

IDA 里的效果：Strings 窗口完全搜不到有意义的字符串，关键字符串（密钥、URL、特征值）全部藏在解密函数里，导致逆向时最直观的线索之一直接消失。

字符串加密通常和其他混淆叠加使用，是"最后一道门"——就算你已经还原了 CFF 和 BCF，关键字符串还是看不到。

对抗方式：动态分析，在运行时 hook 解密函数，等字符串解密完再读——这是 Frida 最典型的用法之一，后面章节会详细讲。


##  五、三种混淆对比

混淆手段  |  打击目标  |  对抗难度  |  对抗思路
---|---|---|---
CFF 控制流平坦化  |  函数整体结构  |  高  |  常量传播，自动化还原
BCF 虚假控制流  |  局部分支  |  中  |  符号执行，识别恒真/恒假
字符串加密  |  关键字符串  |  中  |  动态 hook，运行时拦截

三种混淆可以叠加，叠加之后难度不是相加而是相乘。UnCrackable L3 就是这种情况——这个等 Frida 章节学完再回来打它。
