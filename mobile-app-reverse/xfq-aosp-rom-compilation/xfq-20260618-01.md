## 一、功能目标

统一 ROM 所有插装点的日志输出，双通道：

- **logcat**：实时查看，tag = `xf.{module}`，key=value 格式，人眼可读
- **文件**：完整落盘，`/data/misc/rommgr/<pkg>/xf_trace.jsonl`，JSON Lines，机器可读

大 payload（加密数据、证书等）logcat 打截断版，文件写完整版（堆分配无限制）。

## 三、核心代码

### `xf_log.h`（C/C++ header-only）

```cpp
// 用法：
//   xf_logi("jni",    pkg, "RegisterNatives  class=%s  offset=0x%lx", cls, off)
//   xf_logi("linker", pkg, "dlopen  so=%s  pid=%d", path, pid)
//   xf_logi("crypto", pkg, "#%ld Cipher.init  alg=%s  mode=%s", opId, alg, mode)
//   xf_log_file_raw(pkg, json_line)   // 只写文件，堆分配无限制

#define XF_TRACE_DIR "/data/misc/rommgr"

static inline void xf_log_write(const char* module, const char* pkg,
                                 int priority, const char* msg) {
    char tag[32];
    snprintf(tag, sizeof(tag), "xf.%s", module ? module : "rom");
    __android_log_print(priority, tag, "%s", msg);

    if (pkg == NULL || pkg[0] == '\0') return;

    char path[512];
    snprintf(path, sizeof(path), XF_TRACE_DIR "/%s/xf_trace.jsonl", pkg);
    // ... mkdir + open + write（栈 buf 3800 字节）
}

// 只写文件，堆分配，不截断
static inline void xf_log_file_raw(const char* pkg, const char* msg) {
    // malloc(len + 2)，write，free
}

#define xf_logi(module, pkg, ...) xf_log((module), (pkg), ANDROID_LOG_INFO,  __VA_ARGS__)
#define xf_logw(module, pkg, ...) xf_log((module), (pkg), ANDROID_LOG_WARN,  __VA_ARGS__)
#define xf_loge(module, pkg, ...) xf_log((module), (pkg), ANDROID_LOG_ERROR, __VA_ARGS__)
#define xf_logd(module, pkg, ...) xf_log((module), (pkg), ANDROID_LOG_DEBUG, __VA_ARGS__)
```

### `XfLog.java`（libcore 层）

```java
// logcat + 文件双通道
XfLog.i("crypto", pkg, "#42 Cipher.init  alg=AES/GCM  mode=ENC  keyLen=128");
XfLog.i("jni",    pkg, "RegisterNatives  class=com.example.Foo  offset=0x98c");
```

## 四、logcat 格式（v2，key=value）

```
# JNI 插装
I/xf.jni:    RegisterNatives  class=com.example.Foo  method=nativeInit  so=libfoo.so  offset=0x98c
I/xf.jni:    ImplicitNative  symbol=Java_com_example_Foo_bar  so=libfoo.so  offset=0x17f8
I/xf.jni:    QueryNativeResult  class=com.example.Foo  method=bar  sig=()Z  so=libfoo.so  offset=0x6c170
I/xf.jni:    QueryNativeNotFound  query=com.example.Foo#bar  classLoaded=false

# bionic linker
I/xf.linker: dlopen  so=/data/app/.../libfoo.so  pid=12345

# 加解密（即将加入）
I/xf.crypto: #42 Cipher.init  alg=AES/GCM/NoPadding  mode=ENC  keyLen=128  iv=a1b2c3d4
I/xf.crypto: #42 Cipher.final  inLen=320  outLen=336  in=deadbeef[trunc]  out=cafebabe[trunc]
```

**过滤：**

```bash
adb logcat -s xf.jni:I
adb logcat -s xf.linker:I
adb logcat -s xf.crypto:I
adb logcat -s xf.jni:I xf.crypto:I    # 同时看多个
adb logcat -s xf.jni:I | grep QueryNativeResult
```

**文件（完整 JSON）：**

```bash
adb shell tail -f /data/misc/rommgr/<pkg>/xf_trace.jsonl
adb shell tail -f /data/misc/rommgr/com.xiaofeng.rommanager/xf_trace.jsonl
```

## 六、SELinux

### `xf_rommgr_trace_file` 类型

```
# file.te
type xf_rommgr_trace_file, file_type, data_file_type;

# file_contexts
/data/misc/rommgr(/.*)?    u:object_r:xf_rommgr_trace_file:s0

# app.te（userdebug_or_eng 内）
allow appdomain xf_rommgr_trace_file:dir  { search add_name write create };
allow appdomain xf_rommgr_trace_file:file { create open write append getattr };

# app_neverallows.te（userdebug_or_eng 豁免块）
-xf_rommgr_trace_file
```

### 踩坑：untrusted_app create 被 neverallow 拦截

`app_neverallows.te` 默认规则禁止 `untrusted_app` 对 `file_type` 目录做 `create`。
三方 App 在 enforcing 模式下无法 `mkdir` 子目录，文件落盘静默失败（permissive 正常）。

修法：`allow` 和 `neverallow` 均包入 `userdebug_or_eng()` 宏，两边对齐，user build 不受影响。

### `/data/misc/rommgr` 目录权限

`init.rc` 创建时必须 `0777`，owner=system，否则 app UID 对 other 只有 `r-x`，`mkdir` 被 POSIX 拒绝。

```
# init.rc
mkdir /data/misc/rommgr 0777 system system
```
