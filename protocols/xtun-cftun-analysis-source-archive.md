## 2. Flutter + Go 架构

xTun 采用 **Flutter + Go 混合架构**：

- **Flutter (Dart)**: 负责UI渲染、用户交互、API HTTP请求
- **Go**: 负责核心VPN逻辑、加密解密、隧道管理、cftun协议实现

### 架构图

```
┌─────────────────────────────────┐
│         Flutter (Dart)           │
│  ┌─────────┐  ┌──────────────┐  │
│  │  UI层   │  │  API请求层   │  │
│  └─────────┘  └──────────────┘  │
│           │ FFI / IPC            │
├───────────┼──────────────────────┤
│         Go (cftun)               │
│  ┌─────────┐  ┌──────────────┐  │
│  │ 加密层  │  │  隧道管理    │  │
│  │X25519   │  │  WebSocket   │  │
│  │AES-GCM  │  │  cftun v3    │  │
│  └─────────┘  └──────────────┘  │
└─────────────────────────────────┘
```

### 通信方式

- **Flutter → Go**: FFI (Android) / IPC named pipe (Windows)
- **Go → 服务器**: WebSocket (cftun WebSocket v3 协议)
- **Flutter → API**: HTTPS REST API

| 头 | 值 | 说明 |

## 5. API 请求模板代码

```python
import socket, ssl, json, base64, hashlib
from cryptography.hazmat.primitives.asymmetric.x25519 import X25519PrivateKey, X25519PublicKey
from cryptography.hazmat.primitives import serialization, hashes
from cryptography.hazmat.primitives.kdf.hkdf import HKDF
from Crypto.Cipher import AES

ctx = ssl.create_default_context()
ctx.check_hostname = False
ctx.verify_mode = ssl.CERT_NONE

def b64url_decode(s):
    if isinstance(s, str): s = s.encode()
    pad = (4 - len(s) % 4) % 4
    return base64.urlsafe_b64decode(s + b'=' * pad)

def raw_https(method, path, extra_headers=None, json_body=None):
    s = socket.create_connection(('REDACTED_HOST', 443), timeout=20)
    ss = ctx.wrap_socket(s, server_hostname='REDACTED_HOST')
    parts = [f'{method} {path} HTTP/1.1', 'Host: REDACTED_HOST']
    if extra_headers:
        for k, v in extra_headers.items():
            parts.append(f'{k}: {v}')
    parts.append('User-Agent: Mozilla/5.0')
    parts.append('Connection: close')
    payload = b''
    if json_body is not None:
        payload = json.dumps(json_body).encode()
        parts.append(f'Content-Length: {len(payload)}')
        parts.append('Content-Type: application/json')
    parts.extend(['', ''])
    req = '\r\n'.join(parts).encode() + payload
    ss.send(req)
    resp = b''
    while True:
        try:
            c = ss.recv(65536)
            if not c: break
            resp += c
        except: break
    ss.close()
    idx = resp.index(b'\r\n\r\n')
    return resp[:idx].decode('utf-8','replace'), resp[idx+4:]

# 1. 登录
h, b = raw_https('POST', '/v1/auth/login',
    extra_headers={'Origin': 'https://REDACTED_HOST'},
    json_body={'email': 'REDACTED_ACCOUNT_EMAIL', 'password': 'REDACTED_PASSWORD'})
token = json.loads(b)['data']['token']

# 2. X25519 + 获取配置
pk = X25519PrivateKey.generate()
pub = pk.public_key().public_bytes(
    encoding=serialization.Encoding.Raw,
    format=serialization.PublicFormat.Raw)
pub_b64 = base64.urlsafe_b64encode(pub).rstrip(b'=').decode()

h, b = raw_https('GET', '/v1/public/node/list',
    extra_headers={'Authorization': token, 'Origin': 'https://REDACTED_HOST',
                   'X-Cftun-Config-Key': pub_b64})
cfg_resp = json.loads(b)
```

## 1. 加密方案概述

**算法: X25519-HKDF-SHA256-AES-256-GCM**

配置响应采用混合加密方案，客户端生成临时X25519密钥对，服务器使用ECDH协商共享密钥，通过HKDF派生AES密钥，最后用AES-256-GCM解密。

## 2. 加密信封结构

服务器返回的JSON信封：

```json
{
  "version": 1,
  "algorithm": "X25519-HKDF-SHA256-AES-256-GCM",
  "server_public_key": "<base64url, 32字节>",
  "salt": "<base64url, 32字节>",
  "nonce": "<base64url, 12字节>",
  "ciphertext": "<base64url, 任意长度>"
}
```

## 3. 解密流程

```
┌──────────────────────────────────────────────────┐
│ 1. 客户端生成 X25519 密钥对                        │
│    privateKey, publicKey = X25519.GenerateKey()   │
│    pub_b64 = base64url(publicKey)                 │
│                                                   │
│ 2. 发送 HTTP 请求                                  │
│    Header: X-Cftun-Config-Key = pub_b64           │
│    GET /v1/public/node/list                       │
│                                                   │
│ 3. 服务器返回加密信封                              │
│    {version, algorithm, server_public_key,        │
│     salt, nonce, ciphertext}                      │
│                                                   │
│ 4. ECDH 共享密钥                                   │
│    shared = X25519(clientPrivateKey, serverPub)   │
│                                                   │
│ 5. HKDF 派生 AES 密钥                              │
│    aesKey = HKDF-SHA256(shared, salt, info, 32)   │
│    info = "cftun-config-response-v1"              │
│                                                   │
│ 6. AES-256-GCM 解密                                │
│    AAD = "cftun-config-response-v1" (同info)      │
│    plaintext = AESGCM.Open(nonce, ciphertext, AAD)│
│                                                   │
│ 7. JSON 解析                                       │
│    config = JSON.parse(plaintext)                 │
└──────────────────────────────────────────────────┘
```

## 4. 关键参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 密钥交换 | X25519 ECDH | 椭圆曲线Diffie-Hellman |
| KDF | HKDF-SHA256 | HMAC-based密钥派生 |
| HKDF info | "cftun-config-response-v1" (24字节) | 密钥派生上下文 |
| AAD | "cftun-config-response-v1" (24字节) | 与info相同 |
| Salt | 32字节 (base64url解码) | 服务器随机生成 |
| Nonce | 12字节 (base64url解码) | 标准GCM nonce |
| 密钥长度 | 32字节 (AES-256) | HKDF输出 |
| 加密算法 | AES-256-GCM | 标准GCM: nonce=12, tag=16 |

## 6. 代码示例

```python
# 派生 AES 密钥 (配置响应解密)
spk = b64url_decode(cfg_resp['server_public_key'])
salt = b64url_decode(cfg_resp['salt'])
nonce = b64url_decode(cfg_resp['nonce'])
ct = b64url_decode(cfg_resp['ciphertext'])

# ECDH 共享密钥
shared = pk.exchange(X25519PublicKey.from_public_bytes(spk))

# HKDF 派生
ps = HKDF(
    algorithm=hashes.SHA256(),
    length=32,
    salt=salt,
    info=b'cftun-config-response-v1'
).derive(shared)

# AES-256-GCM 解密
cipher = AES.new(ps, AES.MODE_GCM, nonce=nonce)
cipher.update(b'cftun-config-response-v1')  # AAD
plaintext = cipher.decrypt(ct)
cfg = json.loads(plaintext.decode('utf-8', 'replace'))

# 提取19个节点
nodes = cfg['data']['list'][0]['nodes']
```

```
│   2 bytes terminator (0x00 0x50)             │
├─────────────────────────────────────────────┤
│ entry[1]: ...                                │
│ ...                                          │
│ entry[entryCount-1]: ...                     │
└─────────────────────────────────────────────┘
```

## 3. mode字节

| mode值 | 含义 | 输出后缀 |
|--------|------|----------|
| 0 | plain (普通) | 无 |
| 1 | RR (Round Robin) | ;RR |
| 2 | RD (Random) | ;RD |
| 3 | error | 返回错误 |

mode提取: `byte & 0x03`，高位 `byte & 0xFC` 必须为0。

## 4. entry结构

每个entry结构：

| 偏移 | 长度 | 内容 | 说明 |
|------|------|------|------|
| 0 | 1字节 | type tag | 0x22 ('"') 或 0x23 ('#') |
| 1 | 4字节 | IPv4地址 | 大端序 (如 0xREDACTED_IPV4_BYTES = REDACTED_IPV4) |
| 5 | 2字节 | terminator | 0x00 0x50 (固定) |

总长度: 7字节/entry

## 5. IP提取方式

从4字节IPv4地址提取IP：

```python
# 示例: hex REDACTED_IPV4_BYTES → REDACTED_IPV4
```

## 9. 解析代码

```python
def decode_txt_binary_payload(data: bytes) -> str:
    """解析decodeTXTBinaryPayload格式的二进制数据"""
    if len(data) < 1:
        return ""

    # mode
    mode = data[0] & 0x03
    if mode == 3:
        raise ValueError("invalid mode")
    if data[0] & 0xFC != 0:
        raise ValueError("invalid mode flags")

    # uvarint entryCount
    offset = 1
    entry_count, offset = decode_uvarint(data, offset)

    # 解析entries
    ips = []
    for i in range(entry_count):
        if offset + 7 > len(data):
            break
        type_tag = data[offset]
        ip = f"{data[offset+1]}.{data[offset+2]}.{data[offset+3]}.{data[offset+4]}"
        # terminator = data[offset+5:offset+7]  # 0x00 0x50
        ips.append(f"{ip}:80")
        offset += 7

    result = ",".join(ips)
    if mode == 1:
        result += ";RR"
    elif mode == 2:
        result += ";RD"

    return result

def decode_uvarint(data: bytes, offset: int) -> tuple:
    """Go标准uvarint解码"""
    result = 0
    shift = 0
    while offset < len(data):
        b = data[offset]
        result |= (b & 0x7F) << shift
        offset += 1
        if b & 0x80 == 0:
            break
        shift += 7
    return result, offset
```

```c
// 简化伪代码
string decryptAccessPoint(string accessPoint, string payloadSecret) {
    accessPoint = strings.TrimSpace(accessPoint);
    payloadSecret = strings.TrimSpace(payloadSecret);
```

## 6. 完整解密代码

```python
import base64, hashlib, json
from Crypto.Cipher import AES
from cryptography.hazmat.primitives.asymmetric.x25519 import X25519PrivateKey, X25519PublicKey
from cryptography.hazmat.primitives import serialization, hashes
from cryptography.hazmat.primitives.kdf.hkdf import HKDF

def b64url_decode(s):
    if isinstance(s, str): s = s.encode()
    pad = (4 - len(s) % 4) % 4
    return base64.urlsafe_b64decode(s + b'=' * pad)

# ========== 第一层: 配置响应解密 ==========
# 假设已通过API获取 cfg_resp 和客户端私钥 pk

spk = b64url_decode(cfg_resp['server_public_key'])
salt = b64url_decode(cfg_resp['salt'])
nonce = b64url_decode(cfg_resp['nonce'])
ct = b64url_decode(cfg_resp['ciphertext'])

# ECDH共享密钥
shared = pk.exchange(X25519PublicKey.from_public_bytes(spk))

# HKDF派生AES密钥
aes_key = HKDF(
    algorithm=hashes.SHA256(),
    length=32,
    salt=salt,
    info=b'cftun-config-response-v1'
).derive(shared)

# AES-256-GCM解密
cipher = AES.new(aes_key, AES.MODE_GCM, nonce=nonce)
cipher.update(b'cftun-config-response-v1')  # AAD
plaintext = cipher.decrypt(ct)
cfg = json.loads(plaintext.decode('utf-8', 'replace'))
nodes = cfg['data']['list'][0]['nodes']  # 19个节点

# ========== 第二层: access_point解密 ==========
payloadSecret = nodes[0]['config']['payload_secret']
# = "REDACTED_PAYLOAD_SECRET"

key = hashlib.sha256(payloadSecret.encode()).digest()
# = bytes.fromhex('REDACTED_HEX_MATERIAL')

aad = b'cftun-txt'

for node in nodes:
    raw = b64url_decode(node['access_point'])
    nonce_ap = raw[:12]
    ct_with_tag = raw[12:]
    cipher = AES.new(key, AES.MODE_GCM, nonce=nonce_ap)
    cipher.update(aad)
    pt = cipher.decrypt_and_verify(ct_with_tag[:-16], ct_with_tag[-16:])
    # pt = decodeTXTBinaryPayload格式的二进制数据
    # 解析后得到: "IP:port,IP:port;RR" 或 "IP:port,IP:port;RD"
    print(f"Node {node['id']} ({node['name']}): {pt.hex()}")
```

## 4. 关键发现

### 4.1 两个独立加密方案

Ghidra反编译确认了两个完全独立的加密方案：

**Scheme A: Access Point TXT解密 (传输层)**
```
key = SHA256(accessPoint_string)
aead = AES-256-GCM(key)
nonce = decoded[:12]
ciphertext = decoded[12:]
AAD = "cftun-txt"
plaintext = aead.Open(nonce, ciphertext, AAD)
→ decodeTXTBinaryPayload(plaintext) → "host1:port1,host2:port2;RR"
```

**Scheme B: Config Response解密 (控制面)**
```
sharedSecret = X25519(clientPrivateKey, serverPublicKey)
key = HKDF-SHA256(sharedSecret, salt=32bytes, info="cftun-config-response-v1", len=32)
aead = AES-256-GCM(key)
AAD = "cftun-config-response-v1"
plaintext = aead.Open(nonce=12bytes, ciphertext, AAD)
→ JSON config response
```

### 4.2 AAD值硬编码

AAD值在代码中逐字节构造，不是字符串常量：

| AAD | Hex | 构造方式 |
|-----|-----|----------|
| cftun-txt | 63 66 74 75 6e 2d 74 78 74 | movabs + mov byte |
| cftun-config-response-v1 | 63 66 74 75 6e 2d 63 6f 6e 66 69 67 2d 72 65 73 70 6f 6e 73 65 2d 76 31 | 逐字节构造 |

### 4.3 密钥派生确认

- **配置响应**: X25519 ECDH + HKDF-SHA256
- **Access Point**: 仅SHA256(payloadSecret)，无额外KDF

## 1. 核心结论

**payloadSecret 是服务器端提供的共享密钥**，通过 API 配置响应（X25519-HKDF-SHA256-AES-256-GCM 加密）传递给客户端。

- 不是从 X25519 派生
- 不是从 tunnel_uuid 派生
- 不是从用户密码派生
- 不是从另一个API端点获取
- **就是服务器返回的 "REDACTED_PAYLOAD_SECRET" 字符串本身，直接传给SHA256**

### 5.1 失败原因汇总

| # | 错误参数 | 正确值 | 失败行为 | 原因 | 来源 |
|---|----------|--------|----------|------|------|
| 1 | Path带cf_前缀 `/cf_{upstream}/e/...` | `/{upstream}/e/...` | 404/超时 | isArgo=false时不加cf_前缀 | SA-2 |

### 5.2 详细分析

**失败原因2: Host头带了:80端口**

- 正确: `Host: REDACTED_IPV4`
- 根因: WebSocket标准Host头不带端口（非标准端口才带）
- 来源: SA-3 动态验证

**失败原因3: 用域名Host触发Beaver WAF 403**
- 错误: `Host: REDACTED_HOST`
- 正确: `Host: REDACTED_IPV4`
- 根因: Beaver WAF检测到域名，返回403 Forbidden (ICP未备案)
- 来源: SA-3 动态验证

**失败原因4: User-Agent不是精确的DEV**
- 错误: `User-Agent: Mozilla/5.0`
- 正确: `User-Agent: DEV`
- 根因: nginx/1.31.4检查UA精确匹配DEV，不匹配返回444静默断开
- 来源: SA-2 + SA-3

## 1. 解密步骤

### 步骤1: 登录API获取JWT

```
POST /v1/auth/login
Body: {email, password}
→ 获取 token (JWT)
```

### 步骤2: 生成X25519密钥对并请求配置

```
生成 X25519 密钥对 (clientPrivateKey, clientPublicKey)
GET /v1/public/node/list
Headers: Authorization, Origin, X-Cftun-Config-Key=base64url(clientPublicKey)
→ 获取加密的配置信封
```

### 步骤3: 解密配置响应 (第一层)

```
ECDH: shared = X25519(clientPrivateKey, serverPublicKey)
HKDF: aesKey = HKDF-SHA256(shared, salt, "cftun-config-response-v1", 32)
AES-256-GCM: plaintext = GCM.Open(nonce, ciphertext, AAD="cftun-config-response-v1")
→ JSON配置 (含19个节点)
```

### 步骤4: 提取payloadSecret

```
payloadSecret = nodes[0].config.payload_secret
= "REDACTED_PAYLOAD_SECRET"
```

### 步骤5: 派生access_point解密密钥

```
key = SHA256(payloadSecret.encode())
= SHA256("REDACTED_PAYLOAD_SECRET")
= REDACTED_HEX_MATERIAL
```

### 步骤6: 解密每个节点的access_point (第二层)

```
for each node:
    raw = base64url_decode(node.access_point)
    nonce = raw[:12]
    ct_with_tag = raw[12:]
    cipher = AES.new(key, AES.MODE_GCM, nonce=nonce)
    cipher.update(b"cftun-txt")  # AAD
    plaintext = cipher.decrypt_and_verify(ct_with_tag[:-16], ct_with_tag[-16:])
    # 解析 plaintext → endpoint IPs
```

### 步骤7: 解析二进制payload

```
decodeTXTBinaryPayload(plaintext):
    mode = plaintext[0] & 0x03
    entryCount = uvarint(plaintext[1:])
    for each entry:
        ip = extract_ipv4(entry[1:5])
        port = 80  # 从节点配置获取
    result = ",".join(ips)
    if mode == 1: result += ";RR"
    if mode == 2: result += ";RD"
```

## 3. 加密方案总结

### 3.1 两层加密架构

| 层级 | 算法 | 密钥来源 | AAD | 用途 |
|------|------|----------|-----|------|
| 第一层 | X25519-HKDF-SHA256-AES-256-GCM | ECDH + HKDF | cftun-config-response-v1 (24B) | API配置响应传输 |
| 第二层 | AES-256-GCM | SHA256(payloadSecret) | cftun-txt (9B) | access_point解密 |

### 3.2 第一层: 配置响应传输加密

```
1. 客户端生成X25519密钥对 → 公钥放入 X-Cftun-Config-Key header
2. 服务器返回 {version, algorithm, server_public_key, salt, nonce, ciphertext}
3. shared = X25519(client_priv, server_pub)
4. aesKey = HKDF-SHA256(shared, salt, "cftun-config-response-v1", 32)
5. plaintext = AES-256-GCM(aesKey, nonce, ciphertext, AAD="cftun-config-response-v1")
```

### 3.3 第二层: access_point解密

```
1. raw = base64url_decode(access_point)
2. nonce = raw[:12], ct_with_tag = raw[12:]
3. key = SHA256("REDACTED_PAYLOAD_SECRET")
   = REDACTED_HEX_MATERIAL
4. plaintext = AES-256-GCM(key, nonce, ct_with_tag, AAD="cftun-txt")
5. result = decodeTXTBinaryPayload(plaintext) → "IP:port,IP:port;RR"
```

### 3.4 payloadSecret来源

payloadSecret = "REDACTED_PAYLOAD_SECRET"

- 来自API配置响应解密后的JSON字段 `config.payload_secret`
- 不是从X25519、tunnel_uuid或用户密码派生
- 服务器生成的独立密钥（当前为占位符值）
- 直接传给SHA256生成AES密钥

# xTun 逆向工程完整流程文档

## 一、项目概述

### 1.1 xTun 是什么

xTun 是一款基于 Flutter + Go 的 VPN 应用。前端使用 Flutter 框架构建跨平台 UI，后端核心逻辑由 Go 语言编译为原生二进制。客户端通过 WebSocket 建立加密隧道，经 Cloudflare Argo 隧道或直连方式接入中转节点，实现代理转发。

### 1.2 逆向目标

脱离 xTun 客户端，使用标准 socks5h / http 代理协议接入 xTun 节点网络。具体包括：

- 理解客户端与 API 服务器之间的认证与配置分发协议
- 解密 API 返回的加密节点配置
- 逆向 cftun WebSocket v3 隧道协议的握手与数据通道加密
- 用 Python 独立实现代理客户端，无需依赖 xTun 原始二进制

### 1.3 最终成果

`cftun_proxy_working.py` — 一个独立的 Python 代理脚本，实现了完整的 xTun 协议栈：

- 自动登录 API、获取并解密节点配置
- 建立 WebSocket 连接、完成 cftun v3 握手
- 实现双向加密数据通道
- 提供本地 SOCKS5（socks5h）和 HTTP 代理
- 实测 19 个节点中 5~6 个可用，出口 IP 验证通过

### 步骤 10: cftun 协议握手

**操作：** 实现 open frame 构造、加密和发送，完成隧道握手。

**工具：** Python pycryptodome 库

#### 10.1 Open Frame 明文格式（83 字节）

```
偏移  长度  字段              值
0     1B    frame_type        0x04
1     1B    protection        0x01
2     1B    protocol          0x06
3     1B    ip_ver            0x04 (IPv4)
4     4B    uint32 LE         1
8     4B    dest_ip           目标 IP（大端）
12    2B    port              目标端口（大端）
14    1B    uuid_len          36
15    36B   tunnel_uuid       隧道 UUID
51    32B   clientKey         客户端公钥（X25519）
```

#### 10.2 加密参数

- **算法：** ChaCha20-Poly1305
- **密钥派生：**
  ```
  openKey = HKDF-SHA256(
      material = payloadSecret,
      salt     = None,
      info     = "cftun websocket v3 open key"
  )
  ```
- **Nonce：** 随机 12 字节
- **AAD：** `"cftun websocket v3 open"`

#### 10.3 加密与发送

- 使用 `encrypt_and_digest()`（**不是** `encrypt()`），确保生成 16 字节 Poly1305 tag
- 密文组装：`Frame = nonce(12) + ciphertext(83) + tag(16) = 111 字节`
- 通过 WebSocket binary frame 发送（opcode 0x02，客户端掩码 masking）

---

### 步骤 11: 数据通道实现

**操作：** 实现握手后的双向加密数据通道。

#### 11.1 密钥派生

```
c2sKey = HKDF-SHA256(
    material = payloadSecret,
    salt     = clientKey,
    info     = "cftun websocket v3 client to server key"
)

s2cKey = HKDF-SHA256(
    material = payloadSecret,
    salt     = clientKey,
    info     = "cftun websocket v3 server to client key"
)
```

#### 11.2 数据帧格式

- **Nonce：** `[0, 0, 0, 0] + seq_big_endian_uint64`（序列号大端编码，前 4 字节固定 0）
- **AAD（发送）：** `"cftun websocket v3 client to server" + seq_be64`
- **AAD（接收）：** `"cftun websocket v3 server to client" + seq_be64`
- **加密：** ChaCha20-Poly1305，发送用 c2sKey，接收用 s2cKey
- **序列号：** 每方向独立递增，从 0 开始

## 五、逆向过程中找到并修正的 5 个错误

| 编号 | 错误描述 | 错误原因 | 修正方案 |
|------|----------|----------|----------|
| 1 | Path 多了 `cf_` 前缀 | 静态分析时未区分 `isArgo` 分支 | `isArgo=false` 时 Path 为 `/{upstream}/e/{exit_server_ip}`，无 `cf_` 前缀 |
| 2 | Host 头带了端口 | 误将 `Host: IP:Port` 格式用于 WebSocket 握手 | Host 头使用纯 IP，不带端口号 |
| 3 | User-Agent 不精确 | 未注意大小写敏感 | User-Agent 必须为 `"DEV"`，小写 `"dev"` 被 nginx 返回 444 |
| 4 | Open frame 明文格式错误 | 字段顺序和长度推断有误 | 按步骤 10.1 的 83 字节格式构造，注意 UUID 前 1 字节长度前缀 |
| 5 | ChaCha20-Poly1305 少发 tag | 使用 `encrypt()` 而非 `encrypt_and_digest()` | 必须使用 `encrypt_and_digest()`，发送 `nonce + ciphertext + tag`（111 字节） |

## 八、协议规格速查

### 8.1 连接参数

```
URL:    ws://{endpoint_ip}:80/{upstream}/e/{exit_server_ip}
Host:   {endpoint_ip}
UA:     DEV
TLS:    无
```

### 8.2 握手 Open Frame

```
明文 (83B):
  [04 01 06 04] [01000000] [dest_ip 4B] [port 2B BE]
  [24] [tunnel_uuid 36B] [clientKey 32B]

加密:
  key  = HKDF-SHA256(payloadSecret, salt=None, info="cftun websocket v3 open key")
  nonce = random(12)
  aad  = "cftun websocket v3 open"
  ct, tag = ChaCha20-Poly1305.encrypt_and_digest(key, nonce, plaintext, aad)

发送 (111B):
  WebSocket binary frame: nonce(12) + ct(83) + tag(16)
```

### 8.3 数据通道

```
c2sKey = HKDF-SHA256(payloadSecret, salt=clientKey, info="cftun websocket v3 client to server key")
s2cKey = HKDF-SHA256(payloadSecret, salt=clientKey, info="cftun websocket v3 server to client key")

每帧:
  nonce = [0,0,0,0] + seq.to_bytes(8, 'big')
  aad   = "cftun websocket v3 client to server" + seq.to_bytes(8, 'big')   # 发送
  aad   = "cftun websocket v3 server to client" + seq.to_bytes(8, 'big')   # 接收
  加密  = ChaCha20-Poly1305(c2sKey / s2cKey, nonce, payload, aad)
  seq   += 1 (每方向独立)
```

### 8.4 配置解密

```
Layer 1 (API 响应):
  shared = X25519(client_priv, server_pub)
  key    = HKDF-SHA256(shared, info=...)
  AES-256-GCM.decrypt(key, ciphertext, aad="cftun-config-response-v1")

Layer 2 (access_point):
  key = SHA256(payloadSecret)
  AES-256-GCM.decrypt(key, ciphertext, aad="cftun-txt")
```
