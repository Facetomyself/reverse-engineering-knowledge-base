## 具体表现

1. Session时长分布:
符合对数正态分布(Log-Normal Distribution)
中位数: 45-90秒
均值: 120-180秒(被长尾拉高)
存在极短session(<10秒,误触)和极长session(>30分钟,深度使用)
风控含义:机器流量假如用 uniform(30, 300) 直接生成 session 时长,——均匀分布和对数正态分布的尾部形状差异极大。
2. 打开间隔分布:
大部分间隔集中在1-6小时(日常使用)
存在长尾:12小时(睡眠)、24小时(隔天)、数天(低频App)
符合威布尔分布(Weibull Distribution)
威布尔分数描述"两次打开 App 之间的时间间隔"的概率分布,形状参数 c 反映间隔的规律程度。
(c是威布尔分布的形状参数,控制分布的形状,c觉得了概率密度曲线的走势)
c 越大 → 间隔越集中 → 行为越规律 → 越像机器人c 越小 → 间隔越分散 → 行为越随机 → 越像真人C含义来源<1早期高频,后期稀疏新用户探索期≈1指数分布(无记忆性随机活跃用户
1.0-2.5

3. 每日活跃次数:
符合泊松分布(Poisson Distribution)

泊松分布简单来说:基于某段时间的基准,如果今天超过基准,即视为异常

### 补量难点:

简单的随机数生成器会被轻易识别(下面讲了)
需要从真实数据拟合分布参数,且参数本身也要加噪声(用户个体差异)
不同用户群体的分布参数差异巨大
最难仿造的是跨维度联合分布:session 时长、打开间隔、活跃次数三者在真实用户中存在相关性

伪随机的严格性:
随机性:随机数应该不存在统计学偏差,是完全杂乱的数列。
不可预测性:不能从过去的序列推测出下一个出现的数。
不可重现性:除非数列保存下来,否则不能重现相同的数列。

## 攻击方视角:状态恢复攻击

上面的直方图看起来"很随机"——十个数字各约1000次,完美均匀。但这正是弱伪随机数的陷阱:统计上均匀 ≠ 不可预测。
MT19937 的内部状态由 624 个 32-bit 整数组成(共 19968 bits)。只要攻击者能连续观察到 624个输出值,就可以完全还原内部状态,从而预测后续所有输出。

```
import random
from mt19937predictor import MT19937Predictor  # pip install mt19937predictor
```

# 受害方:用某个种子初始化
random.seed(12345)
# 攻击方:收集 624 个 getrandbits(32) 输出

```
predictor = MT19937Predictor()
```

for _ in range(624):

```
observed = random.getrandbits(32)
```

predictor.setrandbits(observed, 32)
# 此后预测完全准确
for _ in range(10):

```
predicted = predictor.getrandbits(32)
actual    = random.getrandbits(32)
print(f"预测: {predicted}, 实际: {actual}, 匹配: {predicted == actual}")
```

如果你的系统用 random 生成优惠券码、抽奖序号、验证码——攻击者只需批量请求约 624次,就能预测下一个"中奖"号码。

## 种子可预测性:时间戳种子的风险

很多开发者用时间戳作为种子:

```
import random, time
```

# 反面教材:用毫秒时间戳做种子

```
random.seed(int(time.time() * 1000))
token = random.randint(100000, 999999)
```

攻击窗口分析:
攻击者知道请求的大致时间(HTTP 响应头 Date 字段)
毫秒级时间戳搜索空间约 3600 × 1000 = 3,600,000(±1小时)
暴力枚举全部种子,在普通笔记本上 < 1秒 完成
# 攻击方:暴力枚举时间戳种子

```
import random, time
target_token = 847293
```

# 攻击者截获的某个 token

```
request_time = int(time.time() * 1000)
```

for delta in range(-3_600_000, 3_600_000):
random.seed(request_time + delta)

```
candidate = random.randint(100000, 999999)
if candidate == target_token:
print(f"种子找到: {request_time + delta}")
```

# 此后可预测所有后续 token
