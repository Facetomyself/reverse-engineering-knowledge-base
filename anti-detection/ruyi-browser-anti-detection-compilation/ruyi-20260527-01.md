##  安装与使用

###  安装

  *


    pip install ruyiPage --upgrade

** 异步（async/await）支持  ** ：

  *


    pip install ruyiPage[async] --upgrade

` ruyiPage  ` 提供了类似 Playwright 的浏览器安装方式。安装 Python 包后，建议执行：


    python -m ruyipage install


    这个命令会下载 ruyiPage 内部定制版本的 Firefox


###  框架地址：

  *


    https://github.com/LoseNine/ruyipage


特点：

1.ruyiPage过检测自动化框架+配套火狐过检测内核

2.自动配套指纹，直接过Px盾

3.生成邮箱账户、密码等注册成功后自动保存
