# JSVMP 自定义指令集与解释循环

这份参考说明教学用 JSVMP 如何从源码降到自定义字节码，以及解释器如何取指、解码、分发、执行。它不是某个站点的 signature 或 token 卡，也没有可粘贴的解释器。

虚拟化的作用是提高还原成本，把分析拖过可用窗口。看不懂不等于不可还原。生产里只保护核心算法或加密相关逻辑，不要把整份 JS 都放进虚拟机，否则执行开销过大。这里的加密相关逻辑是保护范围，不是 encryption 算法，也不是 signature、token 或 fingerprint。「虚拟化」一词会被用来指几种不同机制；商业保护还会单独做模拟器与物理设备的区分。这些句子不提供产品名、opcode 或绕过步骤。

<a id="decision-flow"></a>

## 降级顺序

构造顺序是：源码，解析成 AST，语义分析，中间表示，把操作拆成更小的原子步骤，定义私有指令集，再按栈或寄存器生成字节码。中间表示用来把前端和字节码隔开，不要从 AST 直接跳到字节码。原子操作保留在「加载、相加、写入」这一层。解析器实现的专名不写入本文。

指令集是开发者私有表：操作码对应指令。教学表可以排得很整齐，生产表不必整齐。操作码表示做什么，操作数表示对谁、做多少、跳到哪里。

## 栈机器与寄存器机器

栈是后进先出。入口在顶，底封住，操作是压入和弹出。SP 是栈指针。

教学口算是常量 10 加 20 再乘 3，结果 90。指令只保留作用：常量压栈，弹出两个操作数做加或乘，返回或打印。步骤是压 10、压 20、加得 30、再压 3、乘、返回，栈回到空。压常量要多读一个立即数，所以程序计数的步长比纯运算指令更大。助记符和具体字节布局不写入本文。

寄存器机器把虚拟 CPU 的槽当寄存器。带变量的求和再乘 2 时，先分配若干槽并填零。混合形态是算术走栈，常量或返回值放寄存器。口算 3 加 5 再乘 2：先得 8，再乘 2 得 16，读到返回就停。立即数只被点名，定义不完整。混合指令的条数前后不一致，不采用任何一个数字。

## 运行时解释循环

运行时解释器仍是 JS，和自定义字节一起交给浏览器里的 V8。其他引擎的差异不在本文展开。

循环是：进入虚拟机，初始化，检查上下文，按虚拟程序计数器取指，解码出操作码和操作数，分发，执行。分发和执行是变化最多的两部分。一条教学指令是一个操作码加零到三个操作数。生产里还会混用函数表、字符串和数字；教学样本一开始没有这三样，也没有浮点。

机器状态包括程序计数、栈指针、寄存器、局部与全局、调用栈和当前帧，以及作用域。嵌套调用靠后进先出的调用栈。帧记下参数，被调完成后弹出。分发器不要叫成调度器，调度器在采集框架里已经是别的专名。

分发有三种机制，都没有可粘贴的源码：

- 状态选择：比较、跳转和顺序藏在状态里，一次只露出一条。
- 表驱动：操作码先落到一张表再执行。
- 线性一次派发：好写、快；没有映射或动态调整时，弄清一条就容易顺着试后面的。这句没有在样本上验证。

动态改映射会增加组合难度。具体数字不采用。执行器必须保语义，不能多也不能少。先压 A 再压 B，和反过来，结果不同。还要注意绑定丢失、相等比较（单等与双等）、异常和异步回调。专名不展开。

## 常量、调用与编码

样本一旦出现常数、字符串和不止一个函数，就需要常数池、字符串池和函数表。入口调用可以不在原始源码里，由构造解释器的人补上。池里的具体字面量前后不一致，不采用。

语义检查覆盖作用域、符号、类型和约束。丢掉未定义标识符、重复声明、无效调用、函数外返回和不支持的节点。指令表是蓝图：操作码、操作数、语义。精确条数前后不一致，不采用。

教学编码按一个字符一个字节处理，低位字节先放，不是 UTF-16 的一字两字节。这是 encoding，不是 encryption。字节由生成器按指令表和操作数宽度吐出。宽度为什么是 2、4 或 5，没有闭合解释，不采用。上下文每次更新程序计数、操作数栈、调用栈和帧。取指可以用位运算。解码是编码的逆过程。生命周期是进入、初始化、循环、退出。

演示没有干净收束：先看到结果，随后运行失败，环境挑剔，还要再改。不能记成样本已跑通，也不能记成浏览器里复现成功。

## 解释器所在的引擎

这段只作解释器跑在什么东西上的背景，不单开 V8 参考。SMI 是 V8 对小整数的内部表示。下一层优化概念是内联缓存，不是在线缓存。解释器基于寄存器。后续优化可以先按整数加法做，类型一变就撤销并退回更早状态。加热循环被用来说明这个撤销，量级约十万次。不能据此写现代 V8 的阶段名、版本或字节码。
