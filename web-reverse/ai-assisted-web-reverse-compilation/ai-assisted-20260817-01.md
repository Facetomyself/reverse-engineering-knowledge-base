#  某书 x-s 拆解（一）：一个请求头，八个字段，先把地图画出来

本文所有内容仅供安全研究与技术学习，目标 App
已脱敏，涉及的密钥表、字母表等关键常量均以占位符代替，不提供可直接批量请求的成品签名器。严禁用于商业或非法用途，否则后果自负。


某书 web 端每个 API 请求都带一个  ` x-s  ` 头，  ` XYS_  ` 开头，一长串看不懂的字符。

网上"解出来了"的文章不少，但大多只贴一段能跑的代码，不讲这串东西  ** 到底由几块拼成、每块管什么  **
。结果就是：换个接口、换个版本，代码一失效，你不知道该改哪。

这个系列不那么写。我先把整张地图画出来，这一篇只干一件事：  ** 把  ` x-s  ` 拆成 8
个字段，每个字段标清楚它是什么、难在哪、放在系列的哪一篇细讲。  **

读完你能拿到一段  ** 可以跑的拆包代码  ** ，把任意一条真实  ` x-s  ` 拆成 8
个字段看清楚。字母表这类关键常量我用占位符，正文会说清怎么自己拿到。


##  一、先看它长什么样


    x-s: XYS_2UQhPsHCH0c1+shlHjIj2erjwjQhyoPTqBPT...
         └┬─┘└──────────────── 一坨 ────────────────┘
         前缀            base64 变体编码的一段 JSON

` XYS_  ` 是固定前缀，剥掉。

剩下的部分  ** 不是标准 base64  ** 。直接拿  ` base64.b64decode  ` 解会报错或解出乱码，因为它用了一张  **
自定义字母表  ** ：把标准的  ` ABCD...  ` 换成了另一种排列。

这是国内前端签名最常见的第一层，不难，但不知道的话第一步就卡死。

##  二、换回标准字母表，它就是一段 JSON

自定义 base64 的破法是固定的：  ** 把自定义字母表和标准字母表做一次字符映射，再走标准解码。  **


    import base64, json

    # 这张表要从签名脚本里自己抠（下一节说怎么抠）
    ALPHA = "自定义64字符字母表，此处省略"   # 占位符
    STD   = "ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789+/"
    R2S   = str.maketrans(ALPHA, STD)

    def decode_xs(xs: str) -> dict:
        body = xs[4:].translate(R2S)                 # 剥 XYS_，换回标准字母表
        body += "=" * ((4 - len(body) % 4) % 4)      # 补 padding
        return json.loads(base64.b64decode(body))

解出来是这样一个对象：


    {
      "x0": "4.4.1",
      "x1": "xhs-pc-web",
      "x2": "Mac OS",
      "x3": "mns0301_2UQhPs...(200字符)",
      "x4": "object",
      "x5": "da5bac...(32位hex)",
      "x6": {"xhs-pc-web": "...(28字符)"},
      "x7": {"xhs-pc-web": "...(32字符)"}
    }

** 8 个字段。  ** 一坨天书，拆开就是一张结构清晰的表。

###  那张字母表怎么拿

不用逆算法，  ` Sources  ` 面板全局搜  ` XYS_  ` ，命中的组装函数附近就有那张 64 字符的常量表，或者搜  ` charAt
` 也能定位到编码器。

这是纯静态的一步，几分钟的事。  ** 我不把表直接贴出来，是因为它 + 后面几篇的东西凑齐就成了成品  ** ，但你自己抠一份毫无难度。

##  三、八个字段，各是什么

按难度分三类，正好对应这个系列后面几篇。

###  常量类：抄一次就行（x0/x1/x2/x4）

字段  |  值  |  含义
---|---|---
x0  |  ` 4.4.1  ` |  签名协议版本
x1  |  ` xhs-pc-web  ` |  平台标识
x2  |  ` Mac OS  ` |  操作系统（跟着 UA 走）
x4  |  ` object  ` |  参数类型

这四个是死值，不同环境略有差异，抓一次抄下来即可。  ** 不含任何算法  ** 。

###  标准算法类：认出来就不难（x5/x6/x7）

这三个的算法都是  ** 公开的标准原语  ** ，难点不在密码学，在"搞清楚谁喂给谁"。


    x5 = MD5(path + body)                     # 请求内容的摘要
    x6 = SHA1( MD5字节(x5) ++ x7 )            # 两层哈希
    x7 = nonce(4字节) ++ SHA1( ssk ++ nonce ) # 带一个会话密钥 ssk

  * •  ** x5  ** 最简单：请求路径拼上 body，取 MD5。GET 没 body 就只 MD5 路径。
  * •  ** x6/x7  ** 咬在一起：x7 里有个 4 字节 nonce 和一段  ` SHA1(ssk ++ nonce)  ` ，x6 又是  ` SHA1(MD5字节 ++ x7)  ` 。
  * • 那个  ` ssk  ` 是  ** 服务端下发的会话密钥  ** ，怎么拿到它、怎么用它，是一次完整的 X25519 + AES-GCM 握手。

x5/x6/x7 的字段依赖链，还有 ssk 握手，放在  ** 系列第（四）篇  ** 细讲，附完整可跑代码。

###  硬核类：一整个虚拟机（x3）


    x3 = "mns0301_" + 自定义base64( RC4(一个144字节的结构体) )

x3 是全场最硬的。它由一个  ** 动态下发、obfuscator.io 混淆过的 JS 虚拟机  ** 算出来，那个 144
字节的结构体里塞了设备指纹、会话计数器、每请求随机数。

x3 一个字段就能拆成好几篇：

  * • 这个 VM 长什么样、handler 怎么藏的
  * • 怎么从执行流里认出它用了 RC4
  * • RC4 的一个性质，让你不发请求就能验证自己对不对
  * • 那 144 字节里最要命的 16 字节，我怎么三次判断错、又怎么纠回来

##  四、别急着信我，自己验一个

拆包只是第一步，  ** 每个字段你都能自己验证是不是那个算法  ** ，不用等到全部逆完。挑最简单的 x5 验一下，建立信心。

x5 说是  ` MD5(path + body)  ` 。抓一条你自己的真实请求，把 URL 的 path 部分和请求 body 拼起来，取 MD5：


    import hashlib

    path = "/api/sns/web/v1/你自己抓的接口路径"
    body = '你抓到的请求 body 原文'          # GET 请求没 body，就传空串
    x5_mine = hashlib.md5((path + body).encode()).hexdigest()

    fields = decode_xs(那条请求的 x_s)
    print("我算的 :", x5_mine)
    print("真实的 :", fields["x5"])
    print("一致？", x5_mine == fields["x5"])

对上了，x5 就实锤了。我在 18 条真实请求上对过，18 条全中。

** 这个"自己拼输入、自己算、跟真值比"的动作，是逆向里最该养成的习惯。  **
每一步都验证，错了立刻知道错在哪一段；等到最后一起验证，错了根本不知道是哪一环。

两个坑提前说：

  * •  ** GET vs POST  ** ：GET 没 body，x5 就是  ` MD5(path)  ` ；POST 才拼 body。
  * •  ** body 要原样  ** ：JSON 的空格、字段顺序、编码，差一个字节 MD5 就全变。直接抄抓包里的原始字节，别自己重新序列化。

x6/x7 也能这么验（它们是 SHA1 链），但要先拿到那个会话密钥 ssk，留到第（四）篇一起。

##  五、把这一篇的东西跑起来

上面的  ` decode_xs  ` 补上字母表就能直接用。拿一条你自己抓包得到的真实  ` x-s  ` ，跑一下：


    xs = "XYS_你自己抓的一条x-s"
    fields = decode_xs(xs)
    for k in sorted(fields):
        v = fields[k]
        print(k, "=", v if isinstance(v, str) else f"{{...}} 嵌套")

你会看到和第二节一模一样的 8 个字段。  ** 这一步不碰任何算法，纯拆包  **
，但它是整个逆向的地基：先看清有几块、每块多大、哪块变哪块不变，才谈得上逐块攻。

很多人一上来就扎进最硬的 x3，卡半个月，其实 x0–x2、x4、x5 半天就能闭合，先把简单的清掉，难点自然孤立出来。

##  六、这一篇记住三点

  1. 1\.  **` x-s  ` =  ` XYS_  ` \+ 自定义base64(一段 8 字段 JSON)  ** 。第一层就是换字母表，别被唬住。
  2. 2\.  ** 8 个字段分三类  ** ：4 个常量抄一次，3 个标准哈希（MD5/SHA1）认出就行，1 个（x3）是独立虚拟机。
  3. 3\.  ** 先拆包看清结构，再逐块攻  ** 。地图画对了，后面每一步都知道自己在哪。
