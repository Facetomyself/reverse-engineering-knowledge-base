## 1.1. 密钥扩展 (Key Expansion)

AES加密需要11个轮密钥(1个初始密钥 + 10轮),我们需要把16字节密钥扩展成11 * 16,如果按照word来,就是44个字(每个字4字节)。
为什么是11个?因为AES-128要做10轮加密,每轮需要一个密钥,加上初始轮需要1个3

## 1.2. 明文填充 (PKCS#7)

AES要求明文必须是16字节的倍数,不够就要填充。
这里用的填充方式是pkcs7,也可以用别的;

```
1
2
3
4
def pkcs7_padding(data: bytes) -> bytes:
"""PKCS#7填充:填充长度等于缺少的字节数"""
pad_len = 16 - (len(data) % 16)
return data + bytes([pad_len] * pad_len)
```

# 2. CBC 模式实现

CBC (Cipher Block Chaining) 是一种分组密码工作模式,通过引入初始化向量(IV)和前一块密文,
使得相同明文块产生不同密文,从而提高安全性。

## 2.1. ECB vs CBC 的区别

### ECB 模式问题

```
1
2
3
明文块1 → AES加密 → 密文块1
明文块2 → AES加密 → 密文块2  ← 相同明文产生相同密文!
明文块3 → AES加密 → 密文块3
```

ECB 缺点:
●
相同明文块产生相同密文块
●
无法隐藏数据模式(例如图片加密会暴露轮廓)
●
容易遭受重放攻击
21

### CBC 模式改进

```
1
2
3
IV ⊕ 明文块1 → AES加密 → 密文块1
密文块1 ⊕ 明文块2 → AES加密 → 密文块2
密文块2 ⊕ 明文块3 → AES加密 → 密文块3
```

CBC 优点:
●
相同明文块产生不同密文(因为与前块密文异或)
●
初始化向量(IV)随机化,增强安全性
●
密文具有扩散性,一个块的改变影响后续所有块

def _key_expansion_flexible(self, key_bytes: bytes) -> list:
"""支持 AES-128/192/256 的密钥扩展"""

Nr = 10  # 轮数
total_words = 44
elif key_len == 24:  # AES-192
Nk = 6
Nr = 12
total_words = 52

Nk = 8
Nr = 14
total_words = 60else:

logger.debug(f"密钥长度: {key_len} 字节 → AES-{key_len*8}, 轮数: {Nr}")
# 1. 初始化前 Nk 个字
words = []for i in range(Nk):
word = key_bytes[i*4 : (i+1)*4]words.append(word)
logger.debug(f"W[{i:02d}] = {list(word)} {word.hex()}")
# 2. 扩展密钥
for i in range(Nk, total_words):
temp = list(words[i - 1])if i % Nk == 0:
# 每 Nk 个字:RotWord + SubWord + Rcon
temp = self.__left_shiftWord(temp, 1)
temp = [self.__get_word_by_wordIdx(byte) for byte in temp]
temp[0] = temp[0] ^ self.RCON[i // Nk - 1]
elif Nk == 8 and i % Nk == 4:
# AES-256 特有:第4个字也要 SubWord
temp = [self.__get_word_by_wordIdx(byte) for byte in temp]
# W[i] = W[i-Nk] ⊕ temp
words.append(bytes(self.__xor_word(temp, words[i - Nk])))
logger.debug(f"W[{i:02d}] = {list(words[i])} {words[i].hex()}")
