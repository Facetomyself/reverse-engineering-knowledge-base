## 正文

日期：2026-06-22  
分支：`feature/crypto-hook-ui-redesign`（基于最新 `dev`：`4b593d6`）

## 目标

把 Java 层算法 Hook 从“外层主开关 + 内层一堆算法开关”改成更接近算法助手的操作模型：

- App 详情页不再出现独立的 Java Crypto Hook 开关，只显示入口和当前状态。
- 进入配置页后，用户只需要打开采集大类；任意大类开启后自动写入 `java_trace=1`。
- AES / SM4 / RSA / Base64 / Zip 等小项不再是采集门禁，而是可选过滤标签。
- 过滤输入框可留空；大类开启且没有过滤条件时采集该大类全部事件。
- 日志页继续独立查看、搜索、清理，不和配置页混在一起。

选中 chip 后变绿，并写入对应大类的 `.filter`；再次点击移除。

## 开关模型

| prop | 含义 |
|------|------|
| `persist.rommgr.app.<pkg>.crypto.sym.enabled` | 对称 Cipher |
| `persist.rommgr.app.<pkg>.crypto.asym.enabled` | 非对称 / 密钥交换 |
| `persist.rommgr.app.<pkg>.crypto.signature.enabled` | 签名 / 验签 |
| `persist.rommgr.app.<pkg>.crypto.digest.enabled` | Hash / HMAC |
| `persist.rommgr.app.<pkg>.crypto.material.enabled` | 密钥、参数、随机数 |
| `persist.rommgr.app.<pkg>.crypto.codec.enabled` | 编码 / 序列化 |
| `persist.rommgr.app.<pkg>.crypto.compress.enabled` | 压缩 / 解压 |
| `persist.rommgr.app.<pkg>.crypto.<group>.filter` | 可选过滤词，逗号分隔，OR 匹配 |
| `persist.rommgr.app.<pkg>.java_trace` | 派生门禁：任意大类开启为 `1`，全部关闭为 `0` |

这版不再兼容旧 UI 的 `hook_aes` / `hook_asym` / `hook_b64` 等细粒度开关语义。

## 覆盖分组

| UI 分组 | 主要覆盖 |
|---------|----------|
| 对称加密 | AES、DES/3DES、SM4、ChaCha、Blowfish、RC2/RC4/RC5、未知 Cipher 兜底 |
| 非对称 / 密钥交换 | RSA、EC/ECDH、DH、XDH、X25519、X448、KeyFactory、KeyAgreement、KeyPairGenerator |
| 签名 / 验签 | RSA Sign、ECDSA、Ed25519、DSA、PSS |
| Hash / HMAC | MD5、SHA-1/256/512、SM3、BLAKE、RIPEMD、HMAC |
| 密钥 / 参数 / 随机数 | SecretKeySpec、KeyGenerator、KDF、KeyStore、AlgorithmParameters、各类 ParameterSpec、SecureRandom |
| 编码 / 序列化 | Base64、Hex、URLCodec、Protobuf |
| 压缩 / 解压 | Deflate、GZip、Zip/Jar、Brotli、LZ4、Snappy、Zstd、XZ/BZip2 |
